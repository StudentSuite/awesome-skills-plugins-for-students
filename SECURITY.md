# Security Policy

## Scope

This repository is a curated list of links. It hosts no application code and
ships no runnable software of its own. The skills and plugins it points to live
in their own repositories and are owned, maintained, and secured by their
respective authors.

## A problem with a listed entry

If a listed skill or plugin looks malicious, has been compromised, or its repo
has been abandoned or taken over:

- Open a [broken or outdated entry issue](../../issues/new/choose), or
- Open a pull request removing the entry.

Please do not post exploit details for a third-party repo in a public issue here;
report those to that project's own security contact first.

## A problem with this repository

For anything affecting this repository itself (the CI workflows, the GitHub
Actions configuration, or a compromised link in our own docs), contact the
[StudentSuite](https://github.com/StudentSuite) organization through GitHub, or
open a private security advisory on this repo. We will respond as promptly as we
can.

## A note for users

This list curates links; it does not vet or host the code behind them. Before
installing any skill or plugin, read its source: it runs with the same
permissions as your coding agent. See the Security Notice in the README for the
full checklist.
